# Contributing

Resource suggestions and corrections are welcome. Check existing IDs and URLs in resources.json before adding duplicates.

## Suggest or correct a resource

1. Provide an official or original source. Explain what is free, eligibility, location, registration requirements and any paid extras.
2. Write an original summary. Do not copy third-party articles, images or trademarks, or use affiliate or shortened links.
3. Update both resources.json and README.md. Keep the existing fields; category must be student, learn, life, english, digital, library or visit. Set checkedAt to the actual review date in YYYY-MM-DD format. Do not refresh dates without reviewing the source.
4. Check whether the other language repository needs the same correction, retain matching resource IDs and describe its status in the PR. Do not claim both editions are synchronised before review.
5. Include the official page reviewed, review date, reason for the change and any uncertainty. Never post identity documents, student IDs, account details, orders or personal contact information.

Maintainers review usefulness, evidence and current availability. There are no paid listings and no requirement to star, share, register or buy. By submitting original material, you agree to license your contribution under this repository's CC BY 4.0 licence. Submit only content you can license.

This repository does not run automated collection, CI or deployment. Validate JSON syntax and manually review the README, links and other language edition.
